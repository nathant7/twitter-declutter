# 🐦 X+ // A Twitter Declutter Extension

X has a lot going on. X+ lets you turn down the bits you don't want, from Grok and Premium promos to trending topics and follow suggestions. And if you miss the bird, it's still here.

[Get X+ from the Firefox Add-ons Store](https://addons.mozilla.org/en-US/firefox/addon/x-4-u/)

[Get X+ from the Chrome Web Store](https://addons.mozilla.org/en-US/firefox/addon/x-twitter-declutter-extension/)

## Features

- **Remove Premium Ads** — Hides Premium promotions and upsells.
- **Remove Grok** — Hides Grok navigation and related controls.
- **Customize sidebar** — Hide or reorder X's native sidebar items. The native More menu is unchanged. Items hidden by another enabled feature are listed as unavailable. Restore default navigation resets the order and visibility preferences.
- **Remove Who to Follow** — Hides follow suggestions.
- **Remove What's Happening** — Hides trending topics.
- **Give 'em the bird!** — Brings back the Twitter bird, changes the popup title to Twitter+, and turns visible “Post” labels back into “Tweet”. X's compact compose icon stays as it is.

Your settings are saved and apply on `x.com` and `twitter.com`.

## Install

To install from source, clone the repository:

```bash
git clone https://github.com/nathant7/twitter-declutter.git
```

- **Chrome or another Chromium browser:** Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the repository folder.
- **Firefox:** Open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on...**, and select `manifest.json`.

Firefox removes temporary add-ons when it closes. A permanent Firefox release needs a Mozilla-signed package.

## Use

Open X, click the X+ toolbar button, and switch features on or off. Choose **Manage sidebar items** to hide or rearrange the navigation. Changes save automatically; no ceremony required.
